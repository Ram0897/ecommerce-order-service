# E-commerce Order Service

Production-ready e-commerce backend built with Java and Spring Boot.

## Planned capabilities

- Product catalog management
- Cart management
- Order lifecycle management
- Inventory management with optimistic locking
- JWT authentication and role-based authorization
- Idempotent order creation
- PostgreSQL persistence with Flyway migrations
- Pagination, filtering, and search
- DTOs and Jakarta validation
- Global exception handling
- OpenAPI / Swagger documentation
- Docker Compose local development
- Unit and integration tests with Testcontainers
- GitHub Actions CI

## Architecture

The project will follow a layered, production-oriented architecture with clear separation between controllers, application/services, persistence, domain models, security, and infrastructure concerns.

## Tech stack

Java 17 · Spring Boot · PostgreSQL · Flyway · Spring Data JPA · JWT · Docker · Testcontainers · GitHub Actions
